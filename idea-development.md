# Idea Development

A limitation that ideally would be addressed is that the agents in this configuration should have the ability to access the tool for writing context data to the vector database. 

Currently, the user is expected to copy out the contextual data, save it to markdown, and upload that to the vector storage. 

This is inefficient and is a process that could and should be automated. 

To overcome this limitation, a tool or function would need to be written allowing the agents to directly write the formulated context data to the vector database or the document collection in the vector database for their personal contextual knowledge.
